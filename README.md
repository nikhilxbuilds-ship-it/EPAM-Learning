**Learner:** Nikhil Kumar

## Objective
Learn the fundamentals of Git and practise a basic version-control workflow.

## What this repository contains
- `notes.md` – concise notes on Git concepts and commands.
- `practice/hello.py` – a small file used for version-control practice.
- `practice-log.md` – steps to perform and record your own Git practice.

## Learning checklist
- [ ] Understand what Git is and why version control is useful.
- [ ] Configure Git username and email.
- [ ] Initialise a local repository.
- [ ] Stage and commit changes.
- [ ] Inspect repository status and commit history.
- [ ] Connect a local repository to GitHub.
- [ ] Push commits to GitHub.
- [ ] Practise creating and merging a branch.

## Important
This is a learning record, not a claim that every item is already completed. Update the checklist only after you have performed and understood each task.
