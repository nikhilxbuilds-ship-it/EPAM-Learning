# Common Git Commands

| Command | Purpose |
|---|---|
| `git --version` | Check Git installation |
| `git config --global user.name "Your Name"` | Set commit author name |
| `git config --global user.email "you@example.com"` | Set commit author email |
| `git init` | Initialise a repository |
| `git status` | Inspect working-tree status |
| `git add filename` | Stage a file |
| `git add .` | Stage changes in the current directory |
| `git commit -m "message"` | Create a commit |
| `git log --oneline` | View compact commit history |
| `git diff` | View unstaged changes |
| `git branch` | List branches |
| `git switch -c branch-name` | Create and switch to a branch |
| `git switch main` | Switch to main |
| `git merge branch-name` | Merge a branch into the current branch |
| `git remote -v` | List remotes |
| `git push -u origin main` | Push main and set upstream |
| `git pull` | Fetch and integrate remote changes |
| `git clone URL` | Copy a remote repository locally |
