# Git – Learning Notes

## What is Git?
Git is a distributed version control system. It tracks changes to files and helps developers work on projects over time.

## Git vs GitHub
- Git is the version-control tool.
- GitHub is an online platform for hosting Git repositories and collaborating.

## Core concepts
- Repository: a project tracked by Git.
- Working directory: files currently being edited.
- Staging area: selected changes prepared for a commit.
- Commit: a saved snapshot of staged changes.
- Branch: a separate line of development.
- Merge: combining changes from branches.
- Remote: a repository hosted elsewhere.

## Basic workflow
Edit files → stage changes → commit changes → push commits to a remote repository.
